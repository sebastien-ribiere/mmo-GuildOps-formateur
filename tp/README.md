# Dossier de TP — Guilde des Hébergeurs

Ce dossier sert de **source de conception**. Les énoncés sous `etudiants/` pourront être publiés dans un dépôt étudiant séparé. Le dossier `formateur/` ne doit **pas** être partagé avec les étudiants. **Attention : ce dépôt GitHub est actuellement public** ; aucun corrigé secret ni solution d'évaluation confidentielle ne doit donc y être ajouté tant qu'il n'est pas rendu privé. Les éléments présents ici décrivent les critères et pistes de correction génériques, sans solutions notées ni secrets.

## Contrat pédagogique commun
1. Chaque groupe constitue une équipe d'architectes missionnée par Castor & Chimères.
2. Chaque mission commence par une demande narrative, contient un **socle**, un **approfondissement** et un **défi facultatif**.
3. Les livrables incluent **une preuve observée** et **une justification** ; l'absence d'erreurs dans les commandes ne suffit pas.
4. Les perturbations sont confinées aux environnements d'exercice, jamais à des systèmes partagés ou de production.
5. Les snapshots/jeux de données sont réinitialisables. Toute suppression est précédée d'une sauvegarde testée.
6. Les solutions cloud doivent avoir une procédure de destruction explicite et un budget plafonné.
